# Archives

Inactive material is retained here so it cannot be mistaken for a supported
runtime entry point.

- `historical_bundles/`: dated controller/model handoffs and their compressed
  source packages;
- `releases/`: old distribution/export trees;
- `import_metadata/`: extraction debris or anomalous imported directory trees
  retained for review rather than deleted.

Nothing under this directory may be imported by production code or selected by
a current deployment profile.
